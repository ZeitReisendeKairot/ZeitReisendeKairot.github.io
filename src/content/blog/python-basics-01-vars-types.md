## 一、有哪些类型？怎么查看类型？

Python 里最常打交道的内置类型：

```python
x = 42          # int    整数（不限大小，永不溢出！）
y = 3.14        # float  浮点数（小数）
ok = True       # bool   布尔（只有 True / False，注意首字母大写）
nothing = None  # NoneType  "没有值"的特殊类型
s = "cat"       # str    字符串

nums = [1, 2, 3]        # list  列表（可变）
point = (1, 2)          # tuple 元组（不可变）
ages = {"tom": 18}      # dict  字典
ids = {1, 2, 3}         # set   集合（自动去重）
```

查看类型有**两种方式**：

```python
type(3.14)          # <class 'float'> —— 直接告诉你它"是"什么
isinstance(3.14, float)  # True —— 问它"是不是"这个类型
```

**区别**（面试常问）：

| | `type(x)` | `isinstance(x, T)` |
| --- | --- | --- |
| 返回 | 精确的类型对象 | True / False |
| 继承 | 只认"亲生类型"，不看父类 | 认类型**及其父类**（含继承关系） |
| 场景 | 调试时看看是啥 | 写代码做类型判断（更稳健） |

一个有趣的例子：**`bool` 是 `int` 的子类**，所以——

```python
type(True) is int              # False：亲生类型是 bool
isinstance(True, int)          # True：继承关系上算 int
True + True                    # 2！（bool 参与运算会被当 1/0）
```

日常写代码判断类型，优先 `isinstance`。

## 二、常用运算符：`/`、`//`、`%`、`**`、`divmod`

```python
7 / 2      # 3.5    —— 真除法：结果永远是 float（哪怕整除，4/2 == 2.0）
7 // 2     # 3      —— 地板除（floor division）：向下取整的商
7 % 2      # 1      —— 取余（模）：a % b 的结果与 a - (a//b)*b 恒等
7 ** 2     # 49     —— 幂运算（平方、立方用它）
divmod(7, 2)  # (3, 1) —— 一步同时拿"商和余数"，返回一个元组
```

**`/` 和 `//` 的最大区别**：`/` 永远返回 float（Python 3 的规矩，和很多语言不同）；`//` 只在两个操作数都是 int 时返回 int。

`divmod` 在算法题里很顺手——比如"把秒数拆成分和秒"：

```python
seconds = 130
m, s = divmod(seconds, 60)   # m=2, s=10（元组可以直接解包）
```

## 三、`-3 // 2` 与 `int(-3 / 2)`：两种完全不同的取整

先看结果：

```python
-3 // 2      # -2   —— 地板除：向"负无穷"方向取整
int(-3 / 2)  # -1   —— 先算 -1.5，int() 再向"零"方向截断
```

**一个向下（负无穷）、一个向零**，负数时结果就分道扬镳了。这就是 Python `//` 的语义：**floor（地板）**，不是"去掉小数"。

配套的 `//` 和 `%` 满足恒等式（这解释了为什么 Python 选 floor 语义）：

```python
# 商 × 除数 + 余数 永远等于被除数
(-3 // 2) * 2 + (-3 % 2)   # (-2)*2 + 1 = -3 ✓
```

注意 `-3 % 2 == 1`（正数！）——Python 的余数符号**跟除数走**，这与 C/Java 不同（它们是 -1）。做循环数组索引、判断奇偶时这一点很关键。

**取整方法全家福**（都在 `math` 模块里，除了 `int` 和 `round`）：

```python
from math import floor, ceil

floor(-1.5)   # -2   —— 向负无穷取整（地板）
ceil(-1.5)    # -1   —— 向正无穷取整（天花板）
int(-1.5)     # -1   —— 向零截断
round(2.5)    # 2    —— 四舍六入五成双（银行家舍入）
round(1.5)    # 2    —— 0.5 时取"偶数"那侧！
round(3.14159, 2)  # 3.14 —— 保留两位小数
```

`round` 的"五成双"是最大的坑：`round(0.5) == 0`、`round(1.5) == 2`、`round(2.5) == 2`——x.5 时取最近的**偶数**。这是为了统计上避免"逢五必进"的系统性偏差（不是 bug，是设计）。

## 四、浮点数陷阱：为什么 `0.1 + 0.2 != 0.3`

```python
0.1 + 0.2 == 0.3        # False ← 刷题时最著名的"幽灵 bug"
print(0.1 + 0.2)        # 0.30000000000000004
```

**原因**：float 用二进制存储，而二进制只能精确表示"分母是 2 的幂"的小数（0.5、0.25、0.125…）。十进制的 0.1 = 1/10，分母含 5，写成二进制是**无限循环小数**——计算机只能存"最接近的近似值"。0.1 和 0.2 存进 float 时各自带了一丁点误差，加起来误差露馅了。

（就像十进制也无法精确表示 1/3 = 0.3333… 一样，只是二进制的"不幸运数字"和十进制不同。）

**正确比较方式一：容差比较（推荐）**

```python
from math import isclose

isclose(0.1 + 0.2, 0.3)                 # True ✓
isclose(a, b)  # 等价于 |a - b| <= rel_tol * max(|a|, |b|)，默认 rel_tol=1e-09
isclose(0.0, 1e-12)                     # False！相对容差对 0 附近失灵
isclose(0.0, 1e-12, abs_tol=1e-9)       # True —— 比较接近 0 的数要加绝对容差
```

**正确比较方式二：手动阈值（很多题解这么写）**

```python
abs(actual - expected) < 1e-9   # 差值小于十亿分之一就认为相等
```

**工程实践**：算钱用 `decimal.Decimal`（精确十进制）；只是显示难看用 `f"{x:.2f}"` 格式化。**永远不要用 `==` 比较浮点数**。

## 五、None：判断与语义

```python
# 判断 None 的唯一正确姿势（PEP 8 规定）
if x is None: ...
if x is not None: ...

# 不要写 == None：
# ① is 比较的是"同一个对象"（身份），比 ==（相等）更快更严格
# ② 对象可以自定义 __eq__ 让 == None 返回乱七八糟的结果，is 不会被欺骗
```

**None 与"零值"的语义区别**（设计 API 时的重要决策）：

| 值 | 语义 | 例子 |
| --- | --- | --- |
| `None` | **没有值**（答案不存在） | 查询数据库没查到记录 |
| `0` | 有一个数值，恰好为零 | 考试得了 0 分（≠没成绩） |
| `""` | 有一个字符串，长度为零 | 用户提交了空的用户名 |
| `[]` | 有一个列表，里面没元素 | 购物车是空的（≠没有购物车） |

坑：布尔上下文里它们**都是"假"**（falsy），`if not x` 分不清"没有值"和"值为零"：

```python
score = 0
if not score: ...        # 进了分支！但你可能只想判断"没成绩"
if score is None: ...    # 不会进——这才是"没有成绩"的判断
```

text = "line 1\nline 2"     # \n 换行

```python
path = r"C:\new\test"       # \n 就是反斜杠+n，不会被当成换行！
regex = r"\d+"              # 正则里 \d 表示数字，加 r 免得写 \\d
```

## 七、`len()`、三种括号、索引与切片

**len() 适用于一切"有长度的东西"**，不只字符串：

```python
len("algorithm")     # 9
len([1, 2, 3])       # 3
len((1, 2))          # 2
len({"a": 1, "b": 2})  # 2 —— 字典的长度 = 键的个数
len({1, 1, 2})       # 2 —— 集合先去重再数
len(123)             # TypeError！数字没有"长度"
```

**三种括号各是什么**（这是新手最容易混的）：

```python
()  # tuple 元组：不可变序列      (1, 2, 3)
[]  # list  列表：可变序列        [1, 2, 3]
{}  # dict  字典（key→value）；{"a": 1}
    # 注意：{} 空花括号是空字典，空集合要写 set()
```

它们都能 `len()`，都能 `in`（`"a" in "cat"` / `2 in [1,2]` / `"a" in {"a": 1}`）。

**索引与切片**：

```python
s = "algorithm"
s[0]       # 'a' —— 索引从 0 开始
s[-1]      # 'm' —— 负索引从尾部倒数（-1 是最后一个）
s[0:3]     # 'alg' —— 切片：[起:止] 左闭右开！取 0,1,2，不含 3
s[2:]      # 'gorithm' —— 省略止 = 到结尾
s[:4]      # 'algo' —— 省略起 = 从开头
s[::2]     # 'agrtm' —— 每隔一个取一个（步长 2）
s[::-1]    # 'mhtirogla' —— 步长 -1 = 反转（回文判断神器）
```

**切片三规则**：

1. **左闭右开** `[起:止)`——含起点、不含止点（这样 `s[:n]` 和 `s[n:]` 正好无缝拼回原串）；
2. **切片越界不报错**：`s[0:100]` 返回整个字符串；但**索引越界会报错**：`s[99]` → IndexError。刷题时这是"温柔的坑"；
3. 步长为负时是"倒着走"：`s[5:1:-1]` 从索引 5 往回取到 2。

## 八、字符串不可变

```python
s = "cat"
# s[0] = "b"        # TypeError！字符串不能原地修改
s = "b" + s[1:]     # 想改？只能拼出一个新字符串 "bat"
```

**"不可变"的意思**：字符串一旦创建，内容就钉死了；所有"修改"操作（replace、upper…）其实都**返回新字符串**，原串毫发无伤：

```python
t = "cat"
t.upper()            # 返回 "CAT"，但 t 还是 "cat"！
t = t.upper()        # 必须接住返回值，t 才变成 "CAT"
```

为什么这么设计？① 安全（做字典 key、函数参数时内容不会被偷改）；② 可共享（多处引用同一份，省内存）。对比：**list 是可变的**，`nums[0] = 9` 直接原地生效。

## 九、什么能当 dict 的 key？——可哈希性

```python
d = {"name": "tom"}     # str   作 key ✓
d2 = {(1, 2): "point"}  # tuple 作 key ✓
d3 = {[1, 2]: "list"}   # TypeError: unhashable type: 'list' ✗
```

dict 内部是一张**哈希表**：每个 key 都会被算成一个"指纹"（哈希值），凭指纹决定它存进哪个格子、从哪个格子取。所以对 key 只有一条要求——**可哈希（hashable）**：

> **key 的哈希值终生不能变。**

- `str`、`int`、`float`、`bool`、`tuple`（且元素也可哈希）：不可变 → 指纹稳定 → ✓
- `list`、`dict`、`set`：可变——今天算的指纹明天就作废，存进去的东西会"找不到家" → ✗

这正是上一节"不可变"的用武之地：**不可变 → 哈希稳定 → 能当 key**，两件事是一件事。

```python
hash("cat")        # 一个整数（每次"运行程序"可能不同，但同一次运行内永远一致）
hash((1, 2))       # ✓ 元组不可变，可哈希
hash([1, 2])       # TypeError！列表可变，不可哈希
hash((1, [2]))     # TypeError！元组本身不可变，但里面装着列表也不行
```

set 的成员资格判断同理（内部也是哈希表）：`{[1, 2]}` 同样报错。

实用技巧：

```python
points = set()          # 想用"坐标列表"查重？
p = [1, 2]
points.add(tuple(p))    # 先转 tuple 再存 ✓
# frozenset 是"冻结集合"，同样可哈希，能当 key
```

## 十、字符串方法全家桶：分割、连接、查找、判断

### 分割与连接

```python
line = "10  20 30"
parts = line.split()          # ["10", "20", "30"]
# 不带参数 = 按任意空白切（多个空格、Tab 都算一个），还会自动去掉首尾空白——刷题读输入的标配
csv_parts = "a,b,c".split(",")  # ["a", "b", "c"] —— 带参数 = 精确按这个分隔符切
"a,,b".split(",")             # ["a", "", "b"] —— 坑：连续分隔符会产生空串！

words = ["hello", "python"]
" ".join(words)               # "hello python" —— 用空格把列表连成字符串
"-".join(["2026", "11", "26"])  # "2026-11-26" —— 用别的连接符
"".join(["a", "b", "c"])      # "abc"
# 坑：join 只能连字符串，数字列表要先转换："-".join(str(x) for x in [1, 2, 3])
```

### 大小写与查找判断

```python
s = "Hello Python"

s.lower()                  # "hello python"（全小写）
s.upper()                  # "HELLO PYTHON"
s.startswith("Hello")      # True（前缀判断）
s.endswith("Python")       # True（后缀判断）
"Python" in s              # True —— 最顺手的"包含"判断
s.find("Python")           # 6 —— 返回第一次出现的索引，找不到返回 -1（不报错）
s.find("Java")             # -1
# s.index("Java")          # 对比：index() 找不到会抛 ValueError（要 try）
s.replace("Python", "World")  # "Hello World"（返回新串，见"不可变"）
"123".isdigit()            # True —— 全是数字字符？
"abc".isalpha()            # True —— 全是字母？
"abc123".isalnum()         # True —— 字母或数字？
```

> 坑一枚：`isalpha` 对**中文也返回 True**（`"中文".isalpha() == True`），因为它判断的是"字母类字符"而非"英文字母"。判断 ASCII 字母用 `"abc".isascii() and "abc".isalpha()`。

## 十一、类型转换与进制

### 基本转换

```python
int("123")        # 123 —— 字符串 → 整数
float("3.14")     # 3.14
str(123)          # "123"
list("abc")       # ["a", "b", "c"] —— 字符串拆成单字符列表
tuple([1, 2])     # (1, 2) —— 列表 → 元组
set([1, 1, 2])    # {1, 2} —— 列表 → 集合（顺便去重！去重经典写法）
```

### 为什么 `int("3.14")` 会报错？

```python
int("3.14")   # ValueError: invalid literal for int() with base 10
```

`int(字符串)` 只认"长得像整数"的字面（数字和正负号），`"3.14"` 里的小数点让它无法直接解析。要**两步走**：

```python
int(float("3.14"))    # 3 —— 先转 float，int() 再向零截断（-3.14 → -3，注意方向）
round(float("3.14"))  # 3 —— 想四舍五入就用 round
float("3.14")         # 3.14 —— 本来就想要小数，直接 float
```

刷题读输入时常见：`input()` 拿到的是字符串，输入是"3 5"这样的两个数——`a, b = map(int, input().split())`。

### 进制转换

```python
int("1010", 2)    # 10 —— 把二进制字符串转成十进制
int("ff", 16)     # 255 —— 十六进制
int("77", 8)      # 63 —— 八进制
bin(10)           # '0b1010' —— 十进制 → 二进制（带 0b 前缀）
hex(255)          # '0xff' —— 十六进制（带 0x 前缀）
oct(8)            # '0o10'
bin(10)[2:]       # '1010' —— 切掉前缀，方便处理
f"{10:b}"         # '1010' —— 格式化写法（同样有 :x :o）
int(bin(5), 2)    # 5 —— bin 和 int(s, 2) 互为逆操作
```

位运算题（LeetCode 190 颠倒二进制位、136 只出现一次的数字）全靠这套转换 + `s[::-1]` 反转。

### B. 编程小题（只用本篇知识）

**B1.** 回文判断：忽略大小写和非字母数字字符（LeetCode 125）。
**B2.** 列表去重且**保持原顺序**。
**B3.** 十进制转任意进制（2–16），负数带负号（LeetCode 504 思路）。

> **答案**
>
> **A1**：`(True, False)`。CPython 把 −5~256 的小整数缓存复用，257 是新建对象。教训：**`is` 比"同一个对象"，`==` 比"值相等"**——日常判断值一律用 `==`，`is` 只留给 `None` / `True` / `False`（缓存是实现细节，勿依赖）。
> **A2**：抛 `TypeError`（元组不可变）**但 `t` 已经变成 `(1, [2, 3, 4])`**！`+=` 先对列表原地追加（成功），再试图把新列表塞回元组槽位（失败）——一半成功一半失败，最阴险的坑。教训：别把可变对象装进"不可变"容器。
> **A3**：`4`（0 + 2 + 2，五成双）。
> **A4**：`False`、`False`。空列表在布尔上下文是 falsy，但 `== False` 并不相等——**falsy ≠ 等于 False**（`==` 不做布尔转换）。
> **A5**：`''`（切片越界安全返回空串）、`IndexError`（索引越界报错）。
> **A6**：`+=` 原地修改 → `x = [1, 2, 3, 4]`；`z = z + [5]` 创建新列表再贴名字 → `x` 不受影响。**Python 变量是"名字标签"不是"盒子"**：`y = x` 是两个标签贴同一个对象。
> **A7**：`1`！`True == 1` 且 `hash(True) == hash(1)`，是同一个 key，后者覆盖前者——bool 是 int 子类的铁证现场。
>
> **B1**：
> ```python
> def is_palindrome(s: str) -> bool:
>     clean = "".join(c.lower() for c in s if c.isalnum())
>     return clean == clean[::-1]
> ```
> **B2**：`list(dict.fromkeys(nums))`——dict 的 key 可哈希且去重，Python 3.7+ 字典保持插入顺序。set 不行（无序）。
> **B3**：
> ```python
> def to_base(n: int, b: int) -> str:
>     if n == 0:
>         return "0"
>     digits = "0123456789abcdef"
>     sign = "-" if n < 0 else ""
>     n = abs(n)
>     out = []
>     while n:
>         n, r = divmod(n, b)     # 一式拿商和余数
>         out.append(digits[r])
>     return sign + "".join(reversed(out))
> ```
